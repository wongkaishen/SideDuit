## 🗄️ Database Schema

### 1. Enable pgvector Extension (Run First!)

```sql
-- Enable vector extension in Supabase
CREATE EXTENSION IF NOT EXISTS vector;
```

### 2. Create Embeddings Table

```sql
CREATE TABLE IF NOT EXISTS public.transaction_embeddings (
  embedding_id bigint generated by default as identity primary key,
  transaction_id bigint,
  upload_id bigint,
  
  -- Document content and metadata
  original_text text not null,
  document_name text,
  document_type text, -- 'receipt', 'invoice', 'payslip', 'gig_receipt', 'bill'
  
  -- Vector embedding (768 dimensions for text-embedding-004)
  embedding vector(768) not null,
  
  -- Enhanced classification
  transaction_category text, -- e.g. 'Food-Restaurant', 'Transport-Ride', 'Income-Freelance'
  merchant_name text,
  amount numeric(10, 2),
  transaction_date date,
  classification_confidence numeric(3, 2), -- 0.00 to 1.00
  
  -- Metadata
  user_id text default '0',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  
  -- Foreign keys
  CONSTRAINT fk_transaction FOREIGN KEY (transaction_id) REFERENCES public.transactions(id) ON DELETE CASCADE,
  CONSTRAINT fk_upload FOREIGN KEY (upload_id) REFERENCES public.update_logs(upload_id) ON DELETE CASCADE
);

-- Indexes for performance
CREATE INDEX idx_embeddings_transaction_id ON public.transaction_embeddings(transaction_id);
CREATE INDEX idx_embeddings_user_id ON public.transaction_embeddings(user_id);
CREATE INDEX idx_embeddings_category ON public.transaction_embeddings(transaction_category);

-- HNSW index for fast vector similarity search
CREATE INDEX idx_embeddings_vector ON public.transaction_embeddings 
USING hnsw (embedding vector_cosine_ops);
```

## 🚀 How It Works

### 1. Upload Processing Flow

When a user uploads a document:

1. **File Upload** → `views.py::upload_view()`
2. **Log Upload** → `services.py::log_upload()` → Get `upload_id`
3. **OCR Extraction** → `services.py::process_document()`
   - Gemini 2.0 Flash analyzes image/PDF
   - Extracts: date, time, amount, merchant, category, items, description
   - Returns structured JSON
4. **Save Transaction** → `services.py::save_transactions_to_supabase()`
   - Insert into `transactions` table
   - Get `transaction_id`
5. **Generate Embedding** → `services.py::generate_embedding()`
   - Create rich text representation
   - Use Gemini `text-embedding-004`
   - Returns 768-dimensional vector
6. **Save Embedding** → `services.py::save_embeddings_for_transactions()`
   - Insert into `transaction_embeddings` table
   - Link with `transaction_id` and `upload_id`

## 🔍 Semantic Search (RAG)

### Example Queries

```sql
-- Find similar transactions to "lunch at McDonald's"
WITH query_embedding AS (
  SELECT embedding FROM transaction_embeddings 
  WHERE original_text ILIKE '%McDonald%' 
  LIMIT 1
)
SELECT 
  te.merchant_name,
  te.transaction_category,
  te.amount,
  te.transaction_date,
  1 - (te.embedding <=> (SELECT embedding FROM query_embedding)) AS similarity
FROM transaction_embeddings te
ORDER BY te.embedding <=> (SELECT embedding FROM query_embedding)
LIMIT 10;
```

### Semantic Search by Text

```sql
-- Convert text to embedding first (in Python)
-- Then query:
SELECT 
  merchant_name,
  transaction_category,
  amount,
  original_text,
  1 - (embedding <=> '[your_query_embedding]') AS similarity
FROM transaction_embeddings
ORDER BY embedding <=> '[your_query_embedding]'
LIMIT 5;
```

## 🤖 MCP Integration

The embeddings enable:

1. **Contextual Understanding** - AI understands spending patterns
2. **Smart Suggestions** - "You often spend at McDonald's on weekdays"
3. **Anomaly Detection** - "This expense is unusual for you"
4. **Budget Insights** - "Your food spending is 20% above average"

### Using with MCP Server

```python
def get_transaction_context(user_query):
    """Get relevant transactions for MCP context"""
    # Generate query embedding
    query_embedding = generate_embedding(user_query)
    
    # Search similar transactions
    conn = get_db_connection()
    cur = conn.cursor()
    
    cur.execute("""
        SELECT original_text, merchant_name, amount, category
        FROM transaction_embeddings
        WHERE user_id = %s
        ORDER BY embedding <=> %s
        LIMIT 5
    """, (user_id, query_embedding))
    
    results = cur.fetchall()
    return results
```

## 🚨 Troubleshooting

### "vector type does not exist"

Run: `CREATE EXTENSION IF NOT EXISTS vector;` in Supabase SQL Editor

### "embedding dimension mismatch"

Ensure using `text-embedding-004` which produces 768-dimensional vectors

### "No embeddings generated"

Check:
1. ✅ GEMINI_API_KEY is set
2. ✅ API quota not exceeded
3. ✅ Transaction text is not empty

### "Slow similarity search"

Create HNSW index:
```sql
CREATE INDEX idx_embeddings_vector ON transaction_embeddings 
USING hnsw (embedding vector_cosine_ops);
```
