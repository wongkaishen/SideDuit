# SideDuit - Quick Start Guide

## 🗄️ Database Architecture

**SideDuit uses ONLY Supabase PostgreSQL** - no SQLite or Django models for data storage.

All financial data is stored in Supabase:
- `transactions` table - All income and expense transactions
- `update_logs` table - Document upload history

---

- Python 3.10+
- Node.js 18+

## ⚡ Quick Setup (5 Minutes)

### 1️⃣ Setup Supabase Database

**Login to Supabase** → SQL Editor → Run these commands:

```sql
-- Create transactions table
CREATE TABLE public.transactions (
  id bigint generated by default as identity primary key,
  year int,
  date date not null,
  time time without time zone,
  transaction_type text not null,
  transaction_amount numeric(10, 2) not null,
  document_id text,
  upload_id bigint,
  user_id text default '0',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

CREATE INDEX idx_transactions_user_id ON public.transactions(user_id);
CREATE INDEX idx_transactions_type ON public.transactions(transaction_type);
CREATE INDEX idx_transactions_date ON public.transactions(date);

-- Create upload logs table
CREATE TABLE public.update_logs (
  upload_id bigint generated by default as identity primary key,
  upload_user text,
  upload_document_name text,
  uploaded_document bytea,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

CREATE INDEX idx_update_logs_user ON public.update_logs(upload_user);
```

### 2️⃣ Backend Setup

**Navigate to backend:**
```bash
cd backend/SideDuit
```

**Create virtual environment:**
```bash
# Windows
python -m venv env
env\Scripts\activate

# Mac/Linux
python3 -m venv env
source env/bin/activate
```

**Install dependencies:**
```bash
pip install -r SideDuit/requirements.txt
```

**Create `.env` file in `backend/SideDuit/` directory:**

```env
# Gemini API for OCR
GEMINI_API_KEY=your_gemini_api_key_here

# Supabase Database
SUPABASE_DB_HOST=db.yourprojectref.supabase.co
SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres
SUPABASE_DB_PASSWORD=your_password_here
SUPABASE_DB_PORT=5432
```

**Get Supabase credentials:**
1. Supabase Dashboard → Settings → Database
2. Look for "Connection String" section
3. Copy Host, Password, etc.

**Get Gemini API key:**
- Visit: https://makersuite.google.com/app/apikey
- Create new API key (free)

**Run server:**
```bash
python manage.py runserver
```

**✅ Test it works:**
Visit: http://127.0.0.1:8000/finance/api/dashboard-summary/

Should see JSON response with financial data!

## 🎯 How It Works

### Data Flow:
```
1. User uploads receipt → Gemini AI extracts data
2. Backend saves to Supabase transactions table
3. Frontend calls Django API endpoints
4. Django queries Supabase
5. Dashboard shows real-time calculations
```

### Key API Endpoints:

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/finance/api/dashboard-summary/` | GET | Total income, expenses, tax |
| `/finance/api/recent-activities/` | GET | Recent transactions |
| `/finance/upload/` | POST | Upload & process documents |

## 🔍 Troubleshooting

### Backend Issues

**"Not Found: /finance/api/dashboard-summary/"**
- ✅ Restart Django server (Ctrl+C, then `python manage.py runserver`)
- ✅ Check `finance/urls.py` has the routes

**"Database connection error"**
- ✅ Check `.env` file exists in `backend/SideDuit/`
- ✅ Verify Supabase credentials are correct
- ✅ Check IP is allowed in Supabase → Settings → Database

**"GEMINI_API_KEY not set"**
- ✅ Add to `.env` file
- ✅ Restart Django server

### Frontend Issues

**"Failed to fetch dashboard summary"**
- ✅ Make sure backend is running on port 8000
- ✅ Check `.env.local` has correct API URL
- ✅ Check browser console for CORS errors

**"No data in dashboard"**
- ✅ Insert sample data in Supabase (see Step 1)
- ✅ OR upload documents via /upload page
- ✅ Check backend terminal for errors
